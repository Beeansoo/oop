Module 3 — Exercises 1–5 (Java Operators)

Java solutions for the first five Module 3 exercises. Each is a standalone program that reads input with Scanner.

File	Exercise
EmpSalCalc.java	Employee Salary Calculator
ShopBillWithVAT.java	Shopping Bill with VAT
CtoFConverter.java	Celsius to Fahrenheit Converter
BMICalc.java	BMI Calculator
WFG.java	Weighted Final Grade
Run
bash
javac FileName.java
java FileName

Example:

bash
javac EmpSalCalc.java
java EmployeeSalaryCalculator

Enter the sample inputs from the workbook and compare the output to the expected result shown in the test case table.

Note: Java requires a file to be named after its public class. These files keep their original class names inside (e.g. BMICalc.java contains public class BMICalculator), so compiling as-is will fail. Either rename each file to match its class name, or open the file and rename the class to match the file name, before running javac.
